Requisitos:

  1. Adicione cor de fundo amarela e altere a cor do texto para marrom apenas no elemento p com o ID imagens.
  2. Mude a cor de fundo da div com ID cabecalho para cinza claro e aumente o tamanho da fonte para 18px.
  3. Altere a cor dos títulos com a classe titulos: h1 em vermelho e h3 em azul. Centralize o texto.
  4. Defina espaçamento entre linhas (line-height) de 1.5 para todos os parágrafos (p), exceto o #imagens que foi estilizado no item 1.
  5. Comente no CSS: que seletor você usou para garantir que o parágrafo com id="imagens" não receba o line-height:1.5.

Questão 3 — Pseudoclasses, pseudoelementos e especificidade (HTML C)

Use os trechos abaixo. Crie um CSS externo (mesmo arquivo) que contenha as regras pedidas.

Este é um exemplo de uso de pseudoelementos e pseudoclasses em CSS.
  1. Adicione um CSS externo e use seletores de classe para colorir text-red e text-blue adequadamente.
  2. Use combinadores: escreva uma regra para .container p e outra para .container > p, explicando brevemente (comentário no CSS) a diferença entre elas.
  3. Aplique estilos nas pseudoclasses de link: a:link, a:visited, a:hover e a:active (escolha cores distintas para cada estado e documente no CSS).
  4. Use pseudoelementos: estilize a ::first-line do .intro, e adicione conteúdo com ::before e ::after na mesma .intro (por exemplo, um ícone textual ou texto curto).
